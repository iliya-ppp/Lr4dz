# Домашнее задание к работе 4

## Условие задачи
 Проверка гипотезы

Ученый проверяет гипотезу о трех числах. Гипотеза подтверждается, если каждое из трех экспериментально полученных чисел (A, B, C) кратно трем. Запишите условие подтверждения гипотезы.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявление целочисленных переменных A, B, C.
3. Ввод переменных  A, B, C.
4. Проверяется составное условие:  
 
   делится ли A на 3 без остатка и B на 3 без остатка и C на 3 без остатка.
     
	• Да (Истина): Вывести на экран сообщение: "Гипотеза верна: все числа кратны трем".

	• Нет (Ложь): Вывести на экран сообщение: "Гипотеза не верна: хотя бы одно число не кратно трем".
